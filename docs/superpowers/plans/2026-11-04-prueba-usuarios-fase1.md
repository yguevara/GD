# Prueba corta con usuarios nuevos: Fase 1

Plan: `2026-11-04-fase1-base-visual.md`, Tarea 6. Medida de exito del spec: un usuario nuevo, con una explicacion de unos minutos, **agrega un documento y encuentra otro por un metadato sin ayuda**.

## Preparacion

- 3 a 5 personas que no hayan usado ArchiGenio. Ninguna participo en el diseno.
- Copia del ejecutable con `config.ini` hacia `SGDTEST_ALCANCE` (nunca `SGDDRHMAIN`). Un usuario con permiso de agregar en al menos una subserie, y documentos cargados con algun metadato buscable (p. ej. una palabra del titulo).
- Explicacion previa de 3 a 5 minutos: que es el arbol de la izquierda (su area), la columna de secciones y la cabecera. No mostrar el flujo de agregar ni de buscar.
- Alguien observa en silencio y anota; cronometro por tarea.

## Tareas

| # | Consigna al usuario | Exito | Tiempo | Ayudas pedidas | Dudas o errores |
|---|---|---|---|---|---|
| 1 | "Agregue un documento nuevo en la subserie X del area Y" | El documento queda creado en la subserie correcta | | | |
| 2 | "Encuentre el documento que contiene Z" (dato que solo esta en un metadato) | Abre el documento correcto desde los resultados | | | |
| 3 | "Busque solo dentro del area en la que esta" | Usa el selector «Solo en ...» | | | |

Registrar tambien: si la pantalla de inicio (sin nodo elegido) les oriento, si encontraron «Agregar documento» y el buscador sin ayuda, y que palabras usaron para describir lo que buscaban.

## Resultado

Fecha, persona observadora, version del ejecutable, tabla completa por participante y conclusiones. Las conclusiones alimentan la Fase 3. Criterio de exito: la mayoria completa las tareas 1 y 2 sin ayuda; cada ayuda pedida es un hallazgo de diseno.
